# Investment research workflow

[← Resources](../README.md)

## Input → Process → Output

| ขั้น | สิ่งที่เข้ามา | งานที่ทำ | สิ่งที่ส่งต่อ |
| --- | --- | --- | --- |
| Input | Filing, transcript, paper, บทความ, ข้อมูลตลาด | เก็บต้นฉบับ วันที่ หน่วย และแหล่งอ้างอิง; สร้าง source note | หลักฐานที่ค้นและตรวจย้อนกลับได้ |
| Process | หลักฐาน + เป้าหมาย + ข้อจำกัด | ใช้กรอบวิเคราะห์ คำนวณด้วย Python ทดสอบสมมติฐาน และหาหลักฐานคัดค้าน | ผลวิเคราะห์พร้อม assumptions และข้อจำกัด |
| Output | ผลวิเคราะห์ที่ตรวจแล้ว | สร้าง memo, portfolio proposal, dashboard และ decision log | ข้อเสนอที่คนทบทวนและรับผิดชอบได้ |

คนกำหนดเป้าหมาย ระยะเวลา ข้อจำกัด สภาพคล่อง และความเสี่ยงที่ยอมรับได้ตั้งแต่ต้น ก่อนทบทวนข้อเสนอและตัดสินใจ

## ลองทำหนึ่งรอบ

1. เลือกบริษัทหนึ่งแห่งและคำถามหนึ่งข้อ เช่น กระแสเงินสดสนับสนุนกำไรที่รายงานหรือไม่
2. เตรียม filing หนึ่งชุดและ transcript หนึ่งรายการจากแหล่งต้นทาง
3. ใช้ [LLM-Wiki](llm-wiki.md) เก็บหลักฐาน พร้อม [Source Note](../templates/source-note.md)
4. เลือกกรอบตรวจหนึ่งเรื่อง เช่น คุณภาพกำไร แล้วบันทึกเป็น [Analysis Method Worksheet](../templates/analysis-method.md)
5. ให้ Python คำนวณส่วนที่ตรวจซ้ำได้ เก็บสูตร หน่วย และช่วงข้อมูลที่ใช้
6. สรุปข้อเท็จจริง สมมติฐาน หลักฐานที่คัดค้าน และคำถามที่ยังตอบไม่ได้
7. ให้คนทบทวนและกรอก [Decision Log](../templates/decision-log.md) ก่อนติดตามผล

## การแบ่งบทบาทเมื่อขยายงาน

| บทบาท | คำถามหลัก | ผลส่งกลับ |
| --- | --- | --- |
| Macro | สมมติฐานเศรษฐกิจใดกระทบการวิเคราะห์ | Scenario พร้อมแหล่งข้อมูลและวันที่ |
| Asset analysis | ธุรกิจ สินทรัพย์ หรือมูลค่ามีเหตุผลอย่างไร | Thesis, assumptions และหลักฐานคัดค้าน |
| Covariance | ข้อมูลความเสี่ยงร่วมมีคุณภาพเพียงใด | วิธีประมาณ ช่วงเวลา และ sensitivity |
| Portfolio construction | พอร์ตตอบเป้าหมายและข้อจำกัดอย่างไร | น้ำหนัก ข้อจำกัด ต้นทุน และผลคำนวณ |
| Risk review | อะไรทำให้ข้อเสนอใช้ไม่ได้ | Stress cases, จุดอ่อน และเงื่อนไขทบทวน |

ตารางนี้เป็นการแบ่งหน้าที่เพื่อออกแบบงาน ไม่ใช่รายชื่อ agents ที่ติดตั้งให้แล้ว บทบาทหลายตัวที่ใช้ข้อมูลหรือโมเดลเดียวกันอาจผิดคล้ายกัน จึงยังต้องตรวจต้นทางและผลคำนวณ
